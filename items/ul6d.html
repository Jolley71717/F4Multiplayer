An extra power armor frame after saving while a companion steps out

Fixed for the next release; we couldn't test it with a companion in a frame.

Mergedstep 6 of 8

If the game saved in the few seconds a companion was stepping out of a friend's frame copy, loading that save brought the copy back as an ordinary frame, one extra suit. The next release still sends the companion out after that load, so the copy no longer comes back. 0.9.2 lists this as a known issue.

The steps

  1. Queued · On the list, not started.
  2. Looked into · Investigated or designed: the cause or the plan is written down.
  3. Built · Written, with tests, waiting for review.
  4. Reviewed · Passed code review.
  5. Rig-tested · Checked on two real games playing together.
  6. Merged · In the next release's code. Before the release goes out, the whole of it is played for several hours straight on two games, to catch rare crashes and problems that only show up over a long session.
  7. Long playtest · In a test build of the release, being played for several hours straight on two games.
  8. Shipped · Out on GitHub and Nexus.
