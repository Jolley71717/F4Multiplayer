Shared storage: one true copy of each home and settlement container

Built and tested on two real games, off by default behind bSharedStorage; a few stress cases wait for the long test.

Shippedstep 8 of 8

Players asked for items in shared storage to stay in step across games. Until now each game held its own copy of a container, so copies could drift: a friend's take removed that item type from your stash, or a load quietly rolled one copy back. With the host setting bSharedStorage on, the host's game keeps the one true copy of each home and settlement container, and everyone's takes and puts go through it. Only ammo, aid and junk are shared this way; weapons, armor, keys and notes stay per player.
