Tutorial hints off in a session, and menus that pause the game

Hints off since 0.9.0; the next release adds a hand-off so enemies don't freeze while someone is in a menu.

Mergedstep 6 of 8

Players asked that tutorial hints not pop up in a session and that menus not freeze things for friends. 0.9.0 turns tutorial hints off during a session (bHideTutorials) and they come back afterward. The next release handles one effect of a menu pausing your game: after five seconds in a menu, the enemies your game runs are handed to a friend nearby so they no longer freeze on the friend's screen. A menu that doesn't pause is tracked separately.

The steps

  2. Looked into · Investigated or designed: the cause or the plan is written down.
  3. Built · Written, with tests, waiting for review.
  4. Reviewed · Passed code review.

  6. Merged · In the next release's code. Before the release goes out, the whole of it is played for several hours straight on two games, to catch rare crashes and problems that only show up over a long session.
  7. Long playtest · In a test build of the release, being played for several hours straight on two games.
  8. Shipped · Out on GitHub and Nexus.
