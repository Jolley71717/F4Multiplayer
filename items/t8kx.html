Moved objects don't reach a friend who loads the area later

Fixed for the next release; not yet tried with a late joiner.

Mergedstep 6 of 8

A moved object only reached games that had it loaded at that moment, so a friend arriving later saw it in the old place. The next release keeps where moved objects came to rest in the session, so a game that loads the area later puts them there too.
